# Spanish (es-419) Localization — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fully localized Latin-American Spanish (es-419) version of the entire Fontletr site under `/es/`, with native ES content targeting real LatAm search intent.

**Architecture:** Approach A — ES content lives in separate `pages-es.json` / `support-pages-es.json`; `build.py` becomes locale-aware (a UI string table `STR[loc]`, locale params on shared chunks, `/es/` routing, hreflang pairing); `engine.js` reads style/UI labels from `PAGE_CONFIG` with English fallback so EN output is unchanged. Spec: `docs/superpowers/specs/2026-05-20-spanish-i18n-design.md`.

**Tech Stack:** Python 3 stdlib static generator (`build.py`), vanilla JS (`assets/engine.js`), pytest for verification.

---

## File Structure

- `tests/test_build.py` — **Create.** pytest suite: builds the site once (session fixture), asserts EN invariants (regression guard) + ES structure (lang, hreflang, slugs, kw-in-title, no English-UI leakage).
- `build.py` — **Modify.** Add `STR` table; make `head` + all shared chunks + builders locale-aware; load ES data; build EN+ES; hreflang pairing; sitemap with both locales.
- `assets/engine.js` — **Modify.** Read `cfg.labels` / `cfg.groups` / `cfg.ui` with English fallback.
- `pages-es.json` — **Create.** ES `site` block + 19 ES generator pages (18 mirrors + `letras-para-nick`).
- `support-pages-es.json` — **Create.** 6 ES support pages.

Conventions reused from the existing code: ES slugs are full paths including the `/es` prefix (home = `/es/`); `out_path()` already does `slug.strip("/")` so `dist/es/<slug>/index.html` falls out for free. Each ES page adds an `alt` field = its EN counterpart slug (omitted on `letras-para-nick`).

```python
def head(title, desc, canonical, loc="en", alternates=None, page_config=None, jsonld=None, extra_meta=""):
    s = STR[loc]
    cfg = ""
    if page_config is not None:
        cfg = "<script>window.PAGE_CONFIG=" + json.dumps(page_config) + ";</script>"
    ld = ""
    if jsonld:
        ld = "".join('<script type="application/ld+json">' + json.dumps(b) + "</script>" for b in jsonld)
    alts = ""
    for hl, href in (alternates or []):
        alts += f'<link rel="alternate" hreflang="{esc(hl)}" href="{esc(href)}">'
    return ('<!DOCTYPE html><html lang="' + esc(s["lang"]) + '"><head><meta charset="UTF-8">'
            '<meta name="viewport" content="width=device-width, initial-scale=1">'
            '<link rel="icon" href="/assets/favicon.svg" type="image/svg+xml">'
            '<link rel="apple-touch-icon" href="/assets/favicon.svg">'
            f'<title>{esc(title)}</title>'
            f'<meta name="description" content="{esc(desc)}">'
            f'<link rel="canonical" href="{esc(canonical)}">'
            f'<meta property="og:title" content="{esc(title)}">'
            f'<meta property="og:description" content="{esc(desc)}">'
            f'<meta property="og:type" content="website"><meta property="og:url" content="{esc(canonical)}">'
            f'<meta property="og:locale" content="{esc(s["og_locale"])}">'
            '<meta name="robots" content="index,follow">'
            f'{alts}{extra_meta}{ADSENSE_HEAD}'
            f'<link rel="stylesheet" href="/assets/styles.css?v={CSS_V}">'
            f'{cfg}{ld}</head><body>')
```

Note: this adds `og:locale` and (when provided) hreflang `<link>`s to EN pages too. Update the EN test in Task 1 is **not** required (it doesn't assert their absence), but EN canonical/title/lang assertions still hold.

def alternates_for(slug, loc):
    """Return [(hreflang, abs_url), ...] incl. self + counterpart + x-default(EN)."""
    out = []
    def absu(s):

def build_sitemap(items):
    urls = []
    for loc, s in items:
        loc_path = "/" if s in ("/", "/es/") else (s if s.endswith("/") else s + "/")
        loc_url_abs = BASE + loc_path
        prio = "1.0" if s in ("/", "/es/") else "0.7"
        urls.append(f"<url><loc>{esc(loc_url_abs)}</loc><changefreq>monthly</changefreq><priority>{prio}</priority></url>")
    xml = ('<?xml version="1.0" encoding="UTF-8"?>'
           '<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">' + "".join(urls) + "</urlset>")
    with open(os.path.join(DIST, "sitemap.xml"), "w", encoding="utf-8") as f:
        f.write(xml)
    with open(os.path.join(DIST, "robots.txt"), "w", encoding="utf-8") as f:
        f.write(f"User-agent: *\nAllow: /\nSitemap: {BASE}/sitemap.xml\n")
    if ADSENSE_CLIENT.startswith("ca-pub-"):
        pub = ADSENSE_CLIENT.replace("ca-", "")
        with open(os.path.join(DIST, "ads.txt"), "w", encoding="utf-8") as f:
