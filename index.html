What it does

It converts the letters you type into Unicode characters that look like other fonts — 𝓬𝓾𝓻𝓼𝓲𝓿𝓮, 𝗯𝗼𝗹𝗱, 𝕕𝕠𝕦𝕓𝕝𝕖-𝕤𝕥𝕣𝕦𝕔𝕜, ꜱᴍᴀʟʟ ᴄᴀᴘꜱ and dozens more. Because it's real text (not an image or a font file), you can paste the result into Instagram and TikTok bios, Discord, X, WhatsApp, game nicknames — pretty much anywhere.

How to use it

Type in the box above. Every style updates instantly. Click Copy on the one you want. Tap the star to pin a style to the top so it's there next time.

Does it work everywhere?

Almost everywhere. A few apps with locked-down fonts will show some characters as empty boxes. If that happens, switch styles — Small caps, Full-width and Bold render the widest.
